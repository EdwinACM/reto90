# Reto 90

App web (PWA) para planear 90 días de entrenamiento y alimentación según tu objetivo: perder grasa, recomposición o ganar músculo.
Un cuestionario inicial calcula tu plan; todo se guarda solo en tu teléfono (sin cuenta, sin servidor).

- Entrenamiento por bloques (uniserie, biserie, triserie), de 3 a 6 días, gimnasio o casa, con cardio en caminadora o elíptica.
- Calorías, macros, porciones y pesos sugeridos calculados con tus datos; menú omnívoro o vegetariano.
- Revisión semanal que propone ajustes de calorías.
- Funciona sin internet una vez abierta. Se puede instalar desde el navegador ("Añadir a pantalla de inicio").

**Aviso:** las cifras son estimaciones y esta app no sustituye a un médico ni a un nutriólogo.
